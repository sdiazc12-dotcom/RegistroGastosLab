# Registro de Gastos - Laboratorio

## Descripción del Proyecto
Aplicación de consola desarrollada en C# utilizando una arquitectura limpia de tres clases (`Gasto`, `GastoRepositorio` y `Program`). El sistema permite gestionar un registro de gastos interactuando con almacenamiento local en archivos CSV y con una base de datos relacional en SQL Server (`GastosDB`), implementando un menú interactivo y validaciones robustas con `TryParse` para el manejo de montos.

## Cómo Ejecutarlo
1. Clonar o descargar este repositorio en tu computadora.
2. Configurar la base de datos `GastosDB` en SQL Server local (`(localdb)\MSSQLLocalDB`) ejecutando el script de creación de la tabla y los registros iniciales.
3. Abrir la solución en Visual Studio y presionar el botón de **Iniciar** para ver el menú en consola.
